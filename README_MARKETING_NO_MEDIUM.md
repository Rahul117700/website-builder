# ⚠️ Important: Medium API No Longer Available

## TL;DR

**Medium stopped providing API access to new users.**

**Solution**: Use Dev.to + Hashnode instead (they're actually better!)

---

## ✅ What You Need Now

### Just 2 Platforms (Not 3!)

1. **Dev.to** - 900K+ developers, excellent engagement
2. **Hashnode** - Your own branded blog, 500K+ readers

### Setup Time: 7 Minutes

```bash
# 1. Setup (1 min)
npm run marketing:setup

# 2. Get Dev.to API key (2 min)
# Go to: https://dev.to/settings/extensions

# 3. Get Hashnode API key (4 min)
# Go to: https://hashnode.com/settings/developer
# Create blog if needed

# 4. Add to .env file
DEVTO_API_KEY=your_key
HASHNODE_API_KEY=your_key
HASHNODE_PUBLICATION_ID=your_id
ENABLED_PLATFORMS=devto,hashnode

# 5. Test it!
npm run marketing:post
```
