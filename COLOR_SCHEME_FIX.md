## Technical Implementation

The colors are applied using inline styles that reference the customizations:

```typescript
// Top bar
style={{
  background: `linear-gradient(90deg, ${primaryColor}, ${secondaryColor})`
}}

// Navigation links
style={{ color: primaryColor }}

// Check icons
style={{ color: primaryColor }}

// Borders
style={{ borderColor: primaryColor }}

// Footer
style={{
  background: `linear-gradient(135deg, ${primaryColor}, ${secondaryColor})`
}}
```

Every element updates in **real-time** when you change the color scheme!
