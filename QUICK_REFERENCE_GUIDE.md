## 📝 Cheat Sheet

### **Button Styles:**
- **Rounded** (default) - Modern, friendly
- **Square** - Professional, corporate
- **Pill** - Playful, high contrast

### **Headline Sizes:**
- **2XL** - Subtle, elegant
- **3XL** - Balanced
- **4XL** (default) - Bold, impactful
- **5XL** - Maximum impact

### **Header Styles:**
- **Sticky** (default) - Always visible, better UX
- **Static** - Traditional, cleaner look

### **Countdown Timer:**
- Toggle ON/OFF
- Set end date/time
- Creates urgency

### **Discount Code:**
- Code: Any text (e.g., "SAVE20")
- Percent: 0-100%
- Shows to customers

### **Reviews:**
- Rating: 1-5 stars (decimals OK)
- Count: Number of reviews
- Builds trust

## ⚡ Quick Tips

### **Best Practices:**
1. Use countdown timers sparingly (special occasions)
2. Set realistic review numbers (10-50 for new products)
3. Test discount codes before launch
4. Choose button style that matches your brand
5. Use sticky header for better navigation

### **SEO Tips:**
1. Write clear, benefit-focused headlines (50-60 chars)
2. Keep descriptions under 160 characters
3. Use high-quality images (1200x630px)
4. Add relevant keywords naturally
5. Test with Google Rich Results Test

## 🆘 Troubleshooting

### **Preview doesn't update:**
- Refresh the page
- Check if changes were saved

### **Discount code not showing:**
- Make sure you entered both code AND percentage
- Save customizations before publishing

### **SEO tags not present:**
- View page source (Ctrl+U)
- Search for "og:" or "schema.org"
- May take 1-2 weeks for search engines to index

### **Reviews not displaying:**
- Toggle "Show Reviews" must be ON
- Enter rating (1-5) and count (>0)
- Save and refresh preview
